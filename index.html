One install. One server. Everyone on the LAN.

ZAI turns a single Windows computer into a private AI server. It finds its own network address and shows it, so anyone on the same Wi-Fi or LAN just opens that address.

Install in a minute

Run ZAI-Setup.exe, pick the drive and folder, done. Python is built in, no admin rights or account needed, and a clean uninstaller is added to Apps.

Open ZAI

Click the ZAI icon on the desktop or Start menu. ZAI becomes a server, opens in your browser and shows the LAN address to share and the admin PIN.

Everyone connects

Phones, tablets and PCs open http://your-ip:8765. Same AI for the whole team, each with their own conversation.

Teach it, and it grows

Paste notes, upload documents, keep good answers. Every future answer is grounded in what ZAI has learned, with sources shown.

Coworkers do the work

Pick a Word writer, Excel analyst, PowerPoint builder or one you design, and export the result as Word, Excel, PowerPoint, PDF, Access, audio or video.

Updates and backs itself up

New version? One tap as admin, or run the newer setup: ZAI checks the fingerprint and restarts, keeping everything. Daily automatic backups, restore in a click.

Three free brains, chosen automatically

ZAI always uses the best brain available and falls back on its own if one stops working. All three are free: no keys, no subscriptions.

Set up in five minutes

  1. Run ZAI-Setup.exe on the computer that will be the server and choose the drive and folder. If Windows says it protected your PC, choose More info then Run anyway. No admin rights needed.
  2. ZAI starts and opens in your browser. Next time, use the ZAI icon on the desktop or in the Start menu.
  3. When Windows asks about the firewall, allow Private networks.
  4. Share the network address shown in the window. Everyone on the LAN can now use ZAI.
  5. For a real offline AI model, run GET-LOCAL-MODEL.bat once while online. ZAI picks it up automatically.

Online, ZAI also answers with ZyeemZia AI for free. PDFs work out of the box. ENABLE-CLOUD.bat adds Claude for anyone with their own paid key. ZAI updates itself from Settings. Running a newer ZAI-Setup.exe also updates an installed ZAI and keeps everything it learned; setup even brings over what an earlier unzipped ZAI learned. Backups and restore are in Settings.

Questions

Is ZAI really free? What about Claude?

Yes, ZAI is free, and so are all three of its brains: the local model, ZyeemZia AI online, and the knowledge vault. Claude is not free: it is billed by Anthropic per use. ZAI keeps it as an optional extra for anyone who wants to add their own Claude API key in Settings; nobody needs it.

Can ZAI make audio, videos or music?

Yes, partly. On Windows ZAI turns any answer into spoken audio (WAV, or MP3 with the free ffmpeg tool) using the built-in voices, and the Video Explainer coworker makes narrated slide videos (MP4, with ffmpeg). Studio writes songs with lyrics, chords, key and tempo. Generating sung music and filmed video needs much heavier AI models; those will arrive through ZAI's automatic updates when they run well on ordinary computers.

Which files can ZAI make?

Every answer and Studio document exports to Word (.docx), Excel (.xlsx), PowerPoint (.pptx), PDF, CSV, a SQLite database, a web page, Markdown, text and JSON, all offline. On Windows it also records audio (WAV) with the built-in voices and makes Access databases when Microsoft Office is installed. With the free ffmpeg tool it adds MP3 audio and narrated MP4 videos.

Can I make my own AI coworkers offline?

Yes. Open Coworkers, press New coworker, give it a name, a role and instructions, and pick its best export. Coworkers are shared on your network, use what ZAI knows, and work fully offline with a local model (run GET-LOCAL-MODEL.bat once). Online, they also work with the free ZyeemZia AI.

Is my copy genuine and safe?

Every official ZAI is sealed: each program file carries a fingerprint, checked every time ZAI starts. If anything has been changed, ZAI shows that the copy is not genuine and, when it is online, restores the official files by itself, keeping everything it has learned. Always download ZAI from zai.zyeemzia.com. ZAI is free to use; changing, unpacking or redistributing it is not allowed (see LICENSE.txt).

How do updates and backups work?

Whenever it is online, ZAI checks zai.zyeemzia.com for a new version. When one is ready, a banner appears; the admin presses Update now, ZAI downloads it, checks its fingerprint and restarts itself. Running a newer ZAI-Setup.exe does the same. Everything it has learned stays exactly as it was. ZAI also backs itself up every day (the last seven are kept), and Settings has Back up now, Restore and reset options, with a safety backup before every change.

Does ZAI really work with no internet?

Yes. With a local model installed (one download while online), ZAI runs entirely on your network. Without a model, it still answers from its knowledge vault. The internet is only used if you choose the optional Claude brain.

How does it "become smarter day by day"?

Through its knowledge vault. Everything you teach (notes, documents, good answers) is stored and searched before every answer, so ZAI answers from your organisation's own knowledge, with sources. This is retrieval-augmented generation (RAG): fast, transparent and fully under your control. You can also move to a bigger local model at any time.

What computer do I need?

Any Windows 10 or 11 PC runs ZAI and the knowledge vault. For a local AI model, the small model runs on most PCs with 8 GB of memory; a graphics card with 8 GB or more makes medium and large models fast.

Is our data private?

Yes. The knowledge, conversations and settings stay in the data folder on the ZAI computer. With the local model or the vault, nothing leaves the network. When ZAI answers online (ZyeemZia AI, or Claude if you add a key), the question and its matching passages are sent to produce the answer; nothing is stored there. Set the brain to Local only in Settings to keep every question inside the building.

Who can change settings?

Settings and removing knowledge need the admin PIN shown in the ZAI window. The admin can also limit teaching to the admin only.

Can others on the LAN not connect?

On the ZAI computer, set the Windows network to Private and allow Python through the firewall for private networks. Make sure both devices are on the same network, then open the address shown in the ZAI window.
